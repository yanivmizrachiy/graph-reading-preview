# קריאת גרפים — מקור אמת יחיד

הריפו `yanivmizrachiy/graph-reading-preview` והענף `main` הם מקור האמת היחיד של החוברת המפורסמת ושל הקורא הדיגיטלי שלה.

## הקבצים הפעילים והסמכות שלהם

- `index.html` — נקודת הכניסה היחידה לקורא. אין ליצור viewer חלופי.
- `graph-reading-workbook.js` — כל לוגיקת הדפדוף, ההתאמה האוטומטית, מונה העמודים ותפריט ההדפסה.
- `graph-reading-workbook.css` — כל עיצוב מעטפת הקורא והכפתורים.
- `מאגר-מלא.html` — מקור ה-HTML היחיד שמוצג בקורא בכל המכשירים.
- `assets/worksheet.css` — עיצוב דפי ה-A4 עצמם.
- `assets/worksheet-bw.css` — התאמות שחור-לבן לצורכי פלט בלבד.
- `assets/pdf/graph-reading-color.pdf` — תוצר PDF צבעוני להורדה ולהדפסה.
- `assets/pdf/graph-reading-bw.pdf` — תוצר PDF שחור-לבן להדפסה.
- `assets/images/` — תמונות החוברת.
- `meta/graph-reading-workbook.json` — מטא-דאטה קנוני: release, מספר עמודים ונתיבי/חתימות תוצרי ה-PDF.
- `scripts/check-viewer-contract.mjs` — בדיקת חוזה אוטומטית שמונעת רגרסיות.

## חוזה התצוגה שאסור לשבור

1. אין שכבת דמו מעל החוברת: אין כותרת שיווקית, אין הסבר "דפדוף נוח", אין כרטיסי `A4 / עמודים / גרסאות`, אין סטטוסים ואין טקסטי עזרה מיותרים.
2. למשתמש מוצגים רק כפתורי פעולה עדינים, ניווט עמודים והחוברת עצמה.
3. אין תפריט "תצוגה", אין בחירת zoom ידנית ואין בחירת מצב תצוגה ידנית. ההתאמה מתבצעת אוטומטית לפי רוחב המסך.
4. הקורא הפעיל מציג תמיד את `מאגר-מלא.html` בכל מחשב, טלפון וטאבלט. אין יותר מסלול PDF לצפייה רגילה ואין הסתעפות לפי סוג מכשיר.
5. ה-PDF אינו מקור לתצוגה השוטפת. הוא משמש רק להורדה ולהדפסה.
6. התצוגה הרגילה היא צבעונית. בחירת `צבעוני / שחור-לבן` מופיעה רק לאחר לחיצה על כפתור `הדפסה`.
7. תפריט ההדפסה סגור כברירת מחדל ונסגר אחרי בחירה, לחיצה מחוץ לתפריט או Escape.
8. בפתיחה ישירה של הקורא החוברת מוצגת כרצף עמודים צמוד: אין רווחים בין עמודים, אין צל בין עמודים, ורק קו כחול כהה `#0f2747` בעובי `3px` מפריד בין עמוד לעמוד.
9. כאשר הקורא מוטמע בתוך אתר אחר מוצג עמוד אחד בלבד בכל פעם, מותאם גם לרוחב וגם לגובה המסגרת. אין סרגל גלילה פנימי נוסף; סרגל הגלילה היחיד של האתר המארח מעוצב בזהב.
10. במצב מוטמע גלגלת העכבר והחלקה אנכית בנייד מעבירות במהירות בין עמודי החוברת. כפתורי קודם/הבא ושדה מספר העמוד נשארים פעילים.
11. בפתיחה ישירה מונה העמודים ממשיך לעקוב אחרי הגלילה בפועל; במצב מוטמע הוא מתעדכן בכל מעבר עמוד.
12. `מאגר-מלא.html` חייב להכיל בדיוק את מספר `.a4-page` שמוגדר ב-`meta/graph-reading-workbook.json`.
13. אין להפנות את הקורא לתיקיות רמה, הסתברות, viewer חלופי או קובץ demo.
14. אין להחזיר `demo.html`, `דפים.html`, `CLAUDE-CODE-HANDOFF.md`, תיקיות `רמה 1`–`רמה 5`, תיקיית `הסתברות`, קבצי `assets/*-fixes.js` או שכבות patch ישנות. ההיסטוריה ב-Git שומרת אותם במקרה של צורך היסטורי.
15. מזהה ה-release חייב להיות זהה ב-`index.html`, ב-`graph-reading-workbook.js` וב-`meta/graph-reading-workbook.json`, וגם פרמטרי ה-cache-busting של CSS/JS חייבים להשתמש באותו release.
16. הסרגל העליון הוא סרגל זהב אחד בלבד; אין להחזיר סרגל פעולה נוסף או סרגל גלילה פנימי במצב מוטמע.
17. נתיבי, גדלי וחתימות SHA-256 של שני קובצי ה-PDF חייבים להתאים למניפסט.

## הגנה מפני רגרסיות

GitHub Actions מריץ את `scripts/check-viewer-contract.mjs` בכל push ובכל pull request. הבדיקה נועדה להיכשל אם מוחזר רכיב דמו, viewer חלופי, תפריט תצוגה, מסלול צפייה ב-PDF, בחירת צבע קבועה, רווחים בין דפים, release לא מסונכרן, מקור תוכן כפול, מונה שאינו עוקב אחרי גלילה, מספר עמודים לא תואם או PDF שאינו תואם למניפסט.

## כלל תחזוקה

אין לבצע תיקון זמני מעל התוצר אם ניתן לתקן את הקוד הפעיל. אין ליצור מקור אמת נוסף. שינוי עתידי צריך לעדכן את הקבצים הפעילים עצמם, לעדכן release באופן עקבי ולעבור את `Viewer contract` לפני שהוא נחשב תקין.
