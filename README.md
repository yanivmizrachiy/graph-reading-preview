# קריאת גרפים — מקור אמת יחיד

הריפו `yanivmizrachiy/graph-reading-preview` והענף `main` הם מקור האמת היחיד של החוברת המפורסמת ושל הקורא הדיגיטלי שלה.

## הקבצים הפעילים והסמכות שלהם

- `index.html` — נקודת הכניסה היחידה לקורא. אין ליצור viewer חלופי.
- `graph-reading-workbook.js` — כל לוגיקת הדפדוף, התאמת המכשיר, מונה העמודים ותפריט ההדפסה.
- `graph-reading-workbook.css` — כל עיצוב מעטפת הקורא והכפתורים.
- `מאגר-מלא.html` — מקור ה-HTML היחיד שמוצג בטלפון ובטאבלט.
- `assets/worksheet.css` — עיצוב דפי ה-A4 עצמם.
- `assets/worksheet-bw.css` — התאמות שחור-לבן לצורכי פלט.
- `assets/pdf/graph-reading-color.pdf` — תוצר PDF צבעוני.
- `assets/pdf/graph-reading-bw.pdf` — תוצר PDF שחור-לבן.
- `assets/images/` — תמונות החוברת.
- `meta/graph-reading-workbook.json` — מטא-דאטה של הגרסה, מספר העמודים ונתיבי התוצרים.

## חוזה התצוגה שאסור לשבור

1. אין שכבת דמו מעל החוברת: אין כותרת שיווקית, אין הסבר "דפדוף נוח", אין כרטיסי `A4 / עמודים / גרסאות`, אין סטטוסים ואין טקסטי עזרה מיותרים.
2. למשתמש מוצגים רק כפתורי פעולה עדינים, ניווט עמודים והחוברת עצמה.
3. אין תפריט "תצוגה", אין בחירת zoom ידנית ואין בחירת מצב תצוגה ידנית. כל מכשיר מקבל התאמה אוטומטית מיטבית.
4. התצוגה הרגילה היא צבעונית. בחירת `צבעוני / שחור-לבן` מופיעה רק לאחר לחיצה על כפתור `הדפסה`.
5. תפריט ההדפסה סגור כברירת מחדל ונסגר אחרי בחירה, לחיצה מחוץ לתפריט או Escape.
6. במובייל ובטאבלט החוברת מוצגת כ-HTML רציף: אין רווחים בין עמודים, אין צל בין עמודים, ורק קו כחול כהה `#0f2747` בעובי `3px` מפריד בין עמוד לעמוד.
7. רוחב דף A4 מותאם אוטומטית לרוחב המכשיר. שינוי גודל חלון או סיבוב המכשיר מחשבים התאמה מחדש.
8. מונה העמודים חייב לעקוב אחרי הגלילה בפועל. אם המשתמש גולל לעמוד 4, בשדה העמוד יוצג `4` גם בלי לחיצה על כפתורי קודם/הבא.
9. כפתורי קודם/הבא ושדה מספר העמוד ממשיכים לעבוד ולגלול לעמוד הנבחר.
10. `מאגר-מלא.html` הוא מקור ה-HTML שה-reader טוען. אין להפנות את הקורא לתיקיות רמה או לקבצי viewer חלופיים.
11. אין להחזיר `demo.html`, `דפים.html`, קבצי `assets/*-fixes.js` או שכבות patch ישנות. ההיסטוריה ב-Git שומרת אותם במקרה של צורך היסטורי.
12. מזהה ה-release חייב להיות זהה ב-`index.html`, ב-`graph-reading-workbook.js` וב-`meta/graph-reading-workbook.json`.

## הגנה מפני רגרסיות

הקובץ `scripts/check-viewer-contract.mjs` בודק אוטומטית את חוזה התצוגה. GitHub Actions מריץ אותו בכל push ובכל pull request. שינוי שמחזיר רכיב דמו, viewer חלופי, תפריט תצוגה, בחירת צבע קבועה, רווחי מובייל, release לא מסונכרן או שמסיר את מעקב מונה העמודים — צריך להיכשל בבדיקה.

## כלל תחזוקה

אין לבצע תיקון זמני מעל התוצר אם ניתן לתקן את הקוד הפעיל. אין ליצור מקור אמת נוסף. שינוי עתידי צריך לעדכן את הקבצים הפעילים עצמם, לעדכן release באופן עקבי ולעבור את `Viewer contract` לפני שהוא נחשב תקין.
