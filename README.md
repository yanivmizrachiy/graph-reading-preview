# קריאת גרפים — חוברת עבודה

זהו הריפו הפעיל של חוברת **קריאת גרפים** ושל התצוגה הדיגיטלית שלה.

## מקור אמת

הענף `main` בריפו הזה הוא מקור האמת של הגרסה המפורסמת. אין להחזיר או להפעיל שכבות patch ישנות מסוג `*-fixes.js`; התיקונים שלהן כבר הוטמעו בתוצר הסופי והקבצים הישנים נשמרים בהיסטוריית Git בלבד.

## קבצים פעילים מרכזיים

- `index.html` — מעטפת הקורא הדיגיטלי.
- `graph-reading-workbook.js` — לוגיקת הקורא, כולל תצוגת מובייל.
- `graph-reading-workbook.css` — עיצוב הקורא.
- `מאגר-מלא.html` — החוברת המלאה ב-HTML; משמשת גם לתצוגה בטלפון ובטאבלט.
- `דפים.html` — תצוגת דפי HTML נוספת.
- `assets/worksheet.css` — עיצוב דפי A4.
- `assets/worksheet-bw.css` — התאמות שחור-לבן.
- `assets/pdf/` — קובצי PDF צבעוני ושחור-לבן.
- `assets/images/` — תמונות החוברת.
- `meta/graph-reading-workbook.json` — מטא-דאטה של הגרסה המפורסמת.

## תצוגת מובייל

בטלפון ובטאבלט הקורא משתמש בגרסת ה-HTML של החוברת. הדפים מוצגים כרצף צמוד ללא רווח וללא צל; קו כחול כהה דק מפריד בין עמוד לעמוד. הורדה והדפסה ממשיכות להשתמש בקובצי ה-PDF.

## קבצים שנוקו

הוסרו מהעץ הפעיל קבצי patch ישנים שלא נטענו עוד וכן `demo.html` ישן ולא מקושר. הם עדיין זמינים בהיסטוריית Git במקרה שנדרש עיון היסטורי.

## כלל תחזוקה

אין להוסיף תיקון זמני שמופעל מעל הפלט הסופי אם ניתן להטמיע את התיקון בקוד הפעיל. יש להימנע מכפילויות, קבצי דמו נטושים ושכבות תיקון שאינן נטענות.
